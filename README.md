
# Sina Barazandeh's Personal Website

This repository contains the source for [sinabr.github.io](https://sinabr.github.io), built with Quarto.

## Local development

Install [Quarto](https://quarto.org/docs/get-started/), then run:

```bash
quarto preview
```

Content is maintained in the root `.qmd` files and the `projects/`, `publications/`, and `posts/` directories.

## Deployment

Pushes to `master` trigger the Quarto Publish workflow. The rendered site is deployed to the `gh-pages` branch.
